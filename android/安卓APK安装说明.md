# JZ的音乐助手（安卓版）— APK 安装与使用说明

> Kotlin + Jetpack Compose 原生安卓应用，完整复刻 iOS 版功能：
> **4 平台并发搜索（QQ/网易/酷我/酷狗）→ 试听 → 多后端取流 → 下载到系统媒体库**。
> 无广告、无账号、无需开发者证书，Android 8.0（API 26）及以上均可安装。

**v1.1 更新（2026-10-28）**：修复「点击搜索后 App 崩溃」问题——原因为所有网络请求被误放在主线程执行（安卓禁止主线程网络请求，OkHttp 同步调用直接触发 NetworkOnMainThreadException 崩溃）；已将所有网络调用强制切换到 IO 线程。若你安装过 v1.0，直接覆盖安装 v1.1 即可（签名一致，数据保留）。

## 一、安装 APK

1. 把 `JZ音乐助手-v1.0-debug.apk` 传到你的安卓手机（微信/QQ 文件助手、网盘、数据线均可）。
2. 在手机上点击 APK 文件开始安装，若提示「不允许安装未知来源应用」：
   - 设置 → 安全 → 安装未知应用 → 允许「文件管理/微信」等来源安装应用；
   - 部分国产系统（MIUI/ColorOS/EMUI）会弹「风险提示」，点「继续安装/仍然安装」即可。
3. 安装完成后打开「JZ的音乐助手」。

## 二、使用说明

| 功能 | 操作 |
|---|---|
| 搜索 | 首页输入关键词（建议带歌手，如「晴天 周杰伦」），4 个平台并发搜索，返回快的平台先显示，失败/超时平台自动忽略 |
| 试听 | 点搜索结果进详情 → 「获取播放/下载链接」→ 任选一条点「试听」 |
| 音质 | 详情页顶部三档：标准 128k / 高品 320k / 无损 FLAC |
| 下载 | 详情页任选一条链接点「下载」；下载页看进度，失败可重试/删除 |
| 保存位置 | 系统媒体库 `Music/JZ音乐助手` 目录——「音乐」App 和「文件」App 都能直接看到，可导入任何播放器 |
| 历史 | 「历史」Tab 查看搜索历史与最近查看 |

## 三、下载任务说明

- 下载在 App 内进行：切后台/锁屏不中断（进程存活时）；**进程被杀则中断**，回下载页点「重试」即可续下（链接短期签名可能失效，重试或换一条链接）。
- 下载完成后文件出现在系统「音乐」App 的专辑/歌曲列表（媒体库自动扫描）。

## 四、第三方源说明（重要）

- 全部音乐源为**实测可用**的第三方接口（酷我系/QQ系/网易云系/酷狗系），**时点性强，随时可能失效**；失效表现多为「解析不到链接」或「下载失败」，重试或换一条链接即可。
- 部分源对 VIP 付费歌曲也能返回全量音频（如酷我 haitangw/nxinxz、QQ cyapi/a.aa.cab、网易 gdstudio/oiapi）。
- 仅供个人学习测试使用，请支持正版音乐。

## 五、常见问题

| 问题 | 处理 |
|---|---|
| 搜索无结果 | 换关键词（带歌手名）；部分平台对周杰伦等版权曲只返回翻唱或空结果 |
| 解析不到链接 | 该音质该源当前不可用，切换音质或过段时间重试 |
| 下载失败 | 点「重试」；链接短期签名过期，换一条源链接下载 |
| 试听卡顿 | 网络或源速度问题，换一条链接 |

## 六、构建信息

- 包名：com.jz.musichelper
- 最低系统：Android 8.0（API 26）；目标系统：Android 14（API 34）
- 技术栈：Kotlin 2.0 + Jetpack Compose + OkHttp + 协程；无第三方广告/统计 SDK
- 源码工程：`JZMusicHelperAndroid/`（可用 Android Studio 打开二次开发）
