## 二类：返回歌词的接口（本轮实测，两项目均连通）

### 2A. LDDC（歌词搜索） — FastAPI

- 源码：`D:\Projects\Private_music\歌词搜索\code\LDDC\lyrics_api_server.py`
- 入口：`GET /lyrics?title=…&artist=…&album=…&source=lrclib/ne/qm/kg`（不传 source 依次回退 LRCLIB→NE→QM→KG）
- 启动：`python -m uvicorn lyrics_api_server:app --host 0.0.0.0 --port 8000`（已实测启动成功；需依赖 httpx/fastapi/uvicorn 及 PySide6-Essentials——logger 模块强依赖）
- 实测（`?title=晴天&artist=周杰伦`）：

| source | HTTP | 结果 |
| --- | --- | --- |
| 不指定（回退链） | 200 | 完整 LRC 2,661 B / 68 行 / 63 个时间戳（经 KG 命中），耗时 30.2s（前三个源失败拖慢） |
| kg（酷狗） | 200 | 同上内容，**0.03s** 返回 |
| lrclib | 404 | 代码层根因：`LrclibAPI.get_lyricslist()` 抛 NotImplementedError，服务端流程强制先取歌词列表，该源结构性不可用（非曲库缺词：lrclib.net 直连 `get` 有该曲 id=17788，instrumental=false） |
| ne（网易云） | 404 | 检索路径在当前网络环境不可用（网易云 legacy 歌词接口直连 200，曲库有词） |
| qm（QQ） | 404 | 检索路径在当前网络环境不可用 |

结论：**连通 ✔，酷狗源开箱即用**；lrclib 源需改代码（跳过 get_lyricslist）才能用，ne/qm 源受平台反爬影响。

### 2B. LrcApi — Flask + waitress

- 源码：`D:\Projects\Private_music\LrcApi`（README 注明为 StreamMusic 配套）
- 入口：`/lyrics`（文本）、`/jsonapi`（多版本 JSON）、`/cover`（封面）、`/tag`（写元数据）；默认 28883
- 启动：`python app.py --port 28883`（已实测启动成功）
- 实测（`?title=晴天&artist=周杰伦`）：

| 路由 | HTTP | 结果 |
| --- | --- | --- |
| `http://127.0.0.1:28883/lyrics` | 200 | 完整 LRC 2,610 B / 68 行 / 63 时间戳，1.45s |
| `http://127.0.0.1:28883/jsonapi` | 200 | JSON 数组 29 KB，含原版/2004 演唱会 Live/林俊杰合唱/Lucky 翻唱等多版本歌词 |
| `http://127.0.0.1:28883/api/v1/lyrics/single` | 200 | 同 /lyrics 内容 |
| 公开 `https://api.lrc.cx/lyrics`（免部署） | 200 | 完整 LRC 2,095 B / 42 时间戳，1.12s |

结论：**连通 ✔，本地与公开 API 均开箱即用**，文本/JSON 双格式，返回内容比 LDDC 更丰富（含 Live 等版本）。

## 归类总结

- **返回音乐的接口**：
  - 官方链路：酷我 mobi.s 与 antiserver（同源同文件，最高 320k MP3，无 FLAC）；GD 解析器（网易翻唱出 FLAC、网易 VIP 曲出全量 mp3）。
  - **GitHub 三仓库可用源 33 条（多曲目重测非废源）**：酷我系（haitangw/nxinxz/zddyr/oiapi/mobi.s/KuwoDES）、QQ 系（cyapi.top/a.aa.cab，可绕过 VIP 出全量 m4a）、网易云系（gdstudio/oiapi Music_163/s0o1，VIP 曲出全量）；其余 67 条已按"3 类测试曲全部无法获取"判为废源剔除。
- **返回歌词的接口**：LDDC（连通，酷狗源可用，lrclib 源结构性 404）＋ LrcApi（连通，本地+公开均可用，含 /jsonapi 多版本）。
- 两类相互独立、互不依赖；音乐类出音频、歌词类出 LRC 文本，可按"音乐 + 歌词"组合使用（LrcApi 的 /cover 可补封面）。

## 局限

- 歌词仅验证《晴天/周杰伦》一曲；ne/qm 源在其他歌曲上可能可用，本次以该曲为准。
- 未对返回歌词做逐字（词级时间轴）判定，仅确认"完整 LRC + 时间戳 + 内容正确"。
- 多曲目重测局限（详见《GitHub音乐源连通性测试报告.md》§4）：类C"网易云独有"实测 0 首入选，判定按 6 首执行；稻香在酷我系链命中为《稻香(DJ Ray 版)》remix（ID3 实证，非原版）；酷我官方对 VIP 曲仅返回 11s 试听片段（不计命中），第三方链可绕过出全量；酷我系链需浏览器 UA/Referer 头，否则 403 防盗链；FLAC >12MB 按上限截断仅记 partial；第三方源具时点性，代理停用后可能失效。
