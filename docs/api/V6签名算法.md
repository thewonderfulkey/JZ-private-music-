## 2. 完整签名算法（每请求）

设 `ts = Date.now()`（毫秒，每请求不同）。

### 2.1 e（32 hex）
```
e = md5(str(ts))
```

### 2.2 to（长度 = len(hex(ts))，逐字节）
```
tsHex = format(ts, 'x')           # 小写十六进制串，如 "1a1a3bc5ee4"
to[i] = e[i] XOR ord(tsHex[i])    # ord = ASCII 码；e[i] 按字节取
```

### 2.3 key5（静态 16 字节）
```
key5 = bf1c05f46b35a6ffd8bf803b21e65942   # = md5("Nd7Sk/2Mj9s/Vdk=")
```

### 2.4 M（乘数，每请求变化）
```
M = ts - 1793634365139            # 固定偏移（常量），观测实证
m = M % 256
```

### 2.5 si16（16 字节）
```
si16[i] = ((key5[i] + 1) * M) % 256   # i = 0..15
```

### 2.6 si（32 hex）
```
si = md5(si16hex + "d41d8cd98f00b204e9800998ecf8427e")   # = md5(si16hex + md5(""))
```

### 2.7 s2（端点相关链，5 步迭代 md5）
```
seed = md5(path|ts|fp|salt)
逐轮追加步骤后缀并 md5：
  rconfig: /L → rx → cS → or → nv
  v4s:     /L → vx → 4S → sr → /v
```
其中 `path` = 请求路径（如 `/rconfig`、`/v4s/url/wy/32507038/128k`）。

### 2.8 s3（仅 v4s）
```
seed = md5(source|id|quality|6|fp|ts|salt)
连续 3 次：seed = md5(seed + salt)
```
注意：**s3 链内 id 用内部 id（实测 wy 源 = 83070523），与 URL path 的取流 id（32507038）不同**。

### 2.9 URL 拼装
```
rconfig: {api}/rconfig?e={e}&to={to}&fp={fp}&s2={s2}&v=6&si={si}
v4s:     {api}/v4s/url/{source}/{id}/{quality}?e={e}&to={to}&fp={fp}&s2={s2}&v=6&si={si}&s3={s3}
```
