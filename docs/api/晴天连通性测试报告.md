# 29 条音乐接口连通性实测报告 —— 以周杰伦《晴天》为测试曲

**测试时间**：2026-10-22（本地时间，美国西岸）
**测试对象**：`Music_API_Audit_and_Downloader.zip` 中的 29 条核心接口记录 + 本地下载 API（music_api.py）
**测试曲**：周杰伦《晴天》（网易云 ID **186016**，专辑《叶惠美》，时长 269 秒，fee=0）
**验证方式**：全部为真实 HTTP 请求；下载文件用「字节数 vs Content-Length + 文件魔数 + FLAC STREAMINFO / MP3 帧扫描时长」三重校验（等价于 ffprobe 的核心检查，本机未装 FFmpeg）

---

## 一、一句话结论

**29 条接口里，没有任何一条能把周杰伦《晴天》原版以「完整无损（FLAC）」直接下载到手**；但发现了一条审计记录之外的可完整下载通道——**酷我 mobi.s 接口返回 200 并成功下载了《晴天》原版完整 MP3（320kbps 高音质，10.8MB，时长 269.9 秒与元数据吻合）**。另外 GD Studio→网易云链路具备完整无损能力（对《晴天》翻唱版实测下载到 24-bit FLAC），但**对周杰伦原版返回空 URL**。

## 三、逐条实测结果（按 api_catalog.json 顺序，共 29 条）

### A. 已验证可完整下载

| # | 项目/接口 | 请求与结果 | 判定 |
| --- | --- | --- | --- |
| 11 | **music-lib/kuwo mobi.s** | `GET https://mobi.kuwo.cn/mobi.s?f=web&source=kwplayercar_ar_6.0.0.9_B_jiakong_vh.apk&from=PC&type=convert_url_with_sign&br=320kmp3&rid=51685512&user=C_APK_guanwang_20261022` → **code:200**，返回 CDN URL；下载 **10,797,030 字节**（320k MP3），ID3 头正常，帧扫描时长 **269.92s** vs 元数据 269s ✓ | ✅ 完整可下载（320k，非无损） |

> 审计记录中该接口曾返回 **code=407 地区限制**（`probe_results.json`）；本次实测同一参数返回 200 并成功下载。**地区/版权限制是动态的**，此为本次最重要的新发现。br=128/320/AAC48 均返回 URL；该曲酷我格式列表为 AAC48/MP3128/MP3H/WMA，**无 FLAC**，故无损不可得。

## 五、无损（FLAC）能力验证 —— GD→网易云链路

为了证明「整条链路是否具备完整无损下载能力」（而非仅针对原版），用同链路对《晴天》翻唱版做了 br=999 实测：

| 曲目 | 结果 |
| --- | --- |
| Lucky小爱《晴天(深情版)》(ID 2652820720) | `GET api.php?types=url&source=netease&id=2652820720&br=999` → FLAC URL（56,037,067 字节，与声明一致）；**完整下载成功**；解析 STREAMINFO：**44.1kHz / 2ch / 24-bit**，总样本 12,302,210，**时长 278.962s**，与网易云元数据 278.96s **吻合（误差 0.002s）**；SHA256 `81847beb68dc3cc8c874b7c96c8e60dab19edf7a37cc622dd1a342ffa2617cda` |
| RyaVocal《晴天(原唱 周杰伦)》(ID 2668397359) | br=999 → FLAC（47,185,529 字节）；**48kHz / 2ch / 24-bit**，时长 270.739s；SHA256 `0c07f3f6eca891fedcd46db539d88f4098ad2e6283b6022cee6a49fcf05e6eb4` |

**结论**：该链路的「无损下载能力」为真（24-bit FLAC 端到端成功），但对周杰伦原版《晴天》被上游拒绝（空 URL）——**版权/歌曲级限制，与音质参数无关**。

另：翻唱版 br=128 下载与审计记录完全一致（4,464,684 字节，SHA256 `6c06e6a9...`，279.01s），佐证了审计数据的可靠性。

## 八、局限说明

- 本次判定基于**周杰伦《晴天》原版**这一首；同一接口对其它歌曲可能不同（如 GD 对翻唱可给 FLAC）。
- 未提供任何账号凭据，Deemix/Qobuz/咪咕/zarz.moe 的「有账号时能否拿到无损」未验证。
- go-music-dl 未在本机编译运行（需要 Go 工具链）；B 站链路被 wbi 签名挡住。
- 未安装 FFmpeg，`ffprobe` 级完整解码核验未做；已用字节数+魔数+STREAMINFO/帧扫描替代，二者在「完整性+时长」判定上等价。
- 音频文件来自公共接口实测，非版权主张；仅作连通性证据保留。
