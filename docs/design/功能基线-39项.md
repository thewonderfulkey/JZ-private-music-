# JZ音乐助手 v2.0.4 UI 改版 · 功能基线（39 项）

> 依据：`JZMusicHelperAndroid/app/src/main/java/com/jz/musichelper/ui/` 各 Screen 源码 + AppState 全局状态。
> 用途：阶段 2 高保真 HTML 原型页面设计依据、阶段 3 Compose 落地回归清单。**保留 v2.0.4 全部功能，只换视觉。**

## 一、全局导航与状态（App 顶层）
1. **5 Tab 底部导航**：HOME 首页 / FAVORITES 收藏 / DOWNLOADS 下载 / HISTORY 历史 / SETTINGS 设置（AppState.tab 全局化，返回键感知）
2. **AppState 全局状态 17 项**：currentSong（播放页覆盖）、lastSong（MiniPlayer）、playlist、playIndex、playMode（循环/随机三态持久化）、theme、tab、searchActive、searchKeyword、searchResults、searching、openPlaylist（编辑精选歌单页）、lastPlayedKey、resolvingSongKey、resolveError、deadSongKeys、连续失败计数
3. **MiniPlayer**：当前播放歌曲存在且不在播放页时，底部常驻迷你播放条
4. **歌单页覆盖**：编辑精选歌单以覆盖层打开（本地内置歌曲，点单曲才联网搜索取流）

## 二、搜索（首页）
5. 搜索框：全平台聚合搜索，SearchService.searchAll 单平台 50 条上限
6. 搜索历史：记录最近关键词，展开显示，可点击直接搜
7. SearchRanker 全平台合并 + 全局排序（去分组、按质量分排序）
8. deadSongKeys 自动隐藏：已确认无源歌曲从搜索结果隐藏；检测中歌曲灰色禁点

## 三、取流（播放链路）
9. UrlResolver.resolveAll + SourcePicker.pick 按音质选源（流畅/标准/高品/无损）
10. resolveAndPlayIfNeeded 全局防重入（同一歌曲并发去重）
11. 连续无源 AUTO_SKIP_MAX=3 自动切歌 + 600ms 失败提示延迟
12. 歌词并发预取 LyricsService.fetch（4h 缓存）

## 四、播放
13. PlayerManager.play/toggle 播放控制
14. completed 事件 → onTrackCompleted 自动连播（列表循环严格按队列顺序）
15. PlayMode 三态：列表循环 / 单曲循环 / 随机播放（持久化）
16. 播放页打开即后台取流，退出不中断；防退出重播（lastPlayedKey）

## 五、MiniPlayer（常驻条）
17. 封面缩略 + 歌名/歌手
18. 收藏 toggle 快捷按钮
19. 上一首 / 播放暂停 / 下一首
20. 无源歌曲点击不进入播放页（仅提示）

## 六、播放页覆盖
21. 大封面 + 歌名 + 歌手
22. 大歌词模式：双击歌词区切换封面/歌词，歌词滑动查看
23. 进度 Slider + 当前时间/总时长
24. 循环三态按钮 + 上一首/播放暂停/下一首
25. 下载弹层：音质选择（流畅/标准/高品/无损）下载

## 七、五 Tab 页
26. 首页：品牌区 + 搜索框 + 编辑精选横条卡 + 热门榜单 + 猜你喜欢双列网格（v1.9.x 阶段化模块）
27. 收藏页：我喜欢的音乐列表（toggleFavorite 心形收藏）
28. 下载页：下载管理列表（DownloadManager 状态：下载中/已完成/失败）+ 删除本地文件（垃圾桶）
29. 历史页：搜索历史 + 最近查看（点击进播放页）
30. 设置页：音质四选 + 主题切换 + 数据管理（清空历史/收藏）+ 关于（版本 v2.0.4）

## 八、返回键层级
31. 播放页 → 歌单页 → 搜索态 → 非首页 Tab → 首页（BackHandler 逐层回退）

## 九、封面体系
32. Coil 加载封面 + QQ 兜底 resolveForce 重试 1 次 + 4s 挂起兜底
33. VinylDetector 黑胶软失败识别（黑胶唱片封面视为无效）
34. CoverResolver 去重 + 并发限流
35. 搜索黑胶展示（封面黑胶判定后展示占位）
36. 热门秒开缓存（热门榜单封面预取缓存）

## 十、主题系统
37. 现状：AppThemeType 四套 —— NIGHTINGALE 夜莺绿 / TWILIGHT 暮山紫 / DEEPSEA 深海蓝 / AMBER 鎏金琥珀（AppPalette 11 字段 + AppBackground 顶部色晕 + 垂直渐变）
38. 目标：新增 5 套认可方向为可切换主题皮肤 —— 墨夜封面（琥珀金黑胶缎面）、黑胶工作室（胡桃木黄铜）、午夜雨窗（玻璃暖橙）、宣纸古风（朱砂印章）、水墨黑白（浓墨山水），保留原 4 套
39. 设置页主题切换 UI 需承载全部主题（原 4 + 新 5）

## 页面结构要点（源码确认）

- **App.kt**：AppState 单例 + MainTab 枚举 + BottomNav + MiniPlayer + openPlaylist 覆盖层；播放页全屏覆盖
- **HomeScreen.kt**（v1.9.0，约 1610 行）：渐变品牌区（AppBackground）+ 搜索栏（展开历史）+ 编辑精选横条卡（124×68 封面 Crop 铺底 + 四类主题色边框）+ 热门榜单（单行列表）+ 猜你喜欢（两列网格，分两段加载）；搜索态：结果双列 + 无源隐藏 + 歌单页覆盖
- **PlayerScreen.kt**（v1.5.2，约 728 行）：封面/歌词双击切换（AnimatedContent）+ 大歌词 + 三态循环 + 进度 Slider + 下载弹层
- **SettingsScreen.kt**：音质 RadioButton 四选 + 主题四选 + 数据管理 + 关于（版本号）
- **FavoritesScreen.kt**：收藏列表 + 心形取消收藏
- **DownloadsScreen.kt**：下载列表 + 垃圾桶删除（DownloadStatus 三态）
- **HistoryScreen.kt**：搜索历史（可清空）+ 最近查看（点击播放）
