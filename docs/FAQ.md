# 常见问题（FAQ）

> 安装步骤见 [QUICKSTART.md](QUICKSTART.md)。版本：iOS `2.4.139 / 317` · Android / Windows `2.4.35`。

**Q：点了某首歌，提示「没有可用的播放源」？**
A：程序已经自动换过平台、并按 2s / 2.5s / 3s 重试过 3 轮。还是不行就说明四家都拿不到（付费、独家、下架或接口临时抽风）。换关键词（加歌手名）或过一会儿再试；连续 3 首都这样会停下来，不会一路跳空。

**Q：为什么有的歌只有 320k，没有无损？**
A：无损是否有货取决于平台，跟客户端无关。iOS 端从无损起取、拿不到自动降档；Windows / Android 可在设置里选默认档位。下载完成后会按文件头 + 体积复核，标称与实际不符会改回来并提示。

**Q：导入歌单失败 / 只导入了一部分？**
A：先看是不是**公开歌单**——私密歌单和别人的「我喜欢的音乐」需要登录，读不到；再确认链接是歌单分享链接（不是单曲或歌手页）。网易云单张歌单最多导前 1000 首（接口上限）。导入的是**快照**，歌单后来更新了，重新导入同一条链接就会替换成新内容，不会多出一张同名歌单。

**Q：导入的歌单能同步吗？会自己更新吗？**
A：不会自动更新。导入时把歌整份存在本机，之后不再联网取歌单；想刷新就重新导一次同一条链接（覆盖旧的）。这个「一次导入、之后离线」是故意的：打开了就有、不会转圈，也不会因为平台改接口突然变空。

**Q：心动模式推的歌不对味 / 能调吗？**
A：它只用本机的五路数据（下载、收藏、导入歌单、搜索、播放）算口味，听得越多越准。设置 → 心动模式里的「熟悉度」滑杆控制新旧比例：向左更多没听过的，向右更多收藏 / 下载过的。碰到不想听的歌，在播放页点「不感兴趣」，之后不会再推这首，同歌手也会降权；设置里可以一键恢复。

**Q：歌词和声音对不上？**
A：iPhone 播放页歌词区有「慢一点 / 快一点 / 归零」，只调当前这一首（按单曲记住），不影响别的歌；同一个歌名不同版本（Live / 重制）前奏差几秒是正常的。Windows / Android 目前不支持微调。

**Q：识曲要多久？为什么开始识别前会突然暂停？**
A：一般 6~12 秒出结果；暂停是**故意的**——不暂停，麦克风收到的是自己放的歌，识别结果会变成「识别到自己」。声源要外放（手机扬声器或音箱）；戴耳机、环境太吵、音量太小都会失败。它不是真内录，版权保护/DRM 音频录不到。

**Q：Windows 提示「未知发布者」、杀软报毒？**
A：发版没有数字签名（签名证书要钱且需要企业资质）。点「更多信息 → 仍要运行」，杀软里加白名单。源码完全公开，可以自己编译核对。

**Q：iPhone 装完 7 天后打不开了？**
A：普通 Apple ID 的个人签名到期，重签一次即可（AltStore 会自动续）。收藏、下载、设置都在 App 沙盒里，重签覆盖安装不会丢。

**Q：下载的歌在哪？**
A：Windows → 程序目录 `Download\`；Android → 系统媒体库 `Music / JZ音乐助手`；iPhone → `文件 › JZ 音乐 › Download`（歌曲 / 歌词 / 封面三个文件夹）。

**Q：会保存我的搜索、收藏到服务器吗？**
A：不会。收藏、最近播放、搜索历史、识曲历史都只存在本机（Windows 在 `Data\`，Android 在应用私有目录，iPhone 在沙盒）。没有账号体系，不上传行为。

**Q：为什么没有 CarPlay / 悬浮歌词？**
A：CarPlay 车机界面要 Apple 单独审批的 `com.apple.developer.carplay-audio`，自签拿不到；iOS 也不允许跨 App 浮窗。能做的「连车载蓝牙自动接着播」已经做了，歌词在播放页/锁屏里显示。
