| 区间 | 动作 |

| 120 – 1140 | **墨渐凝成**：`opacity 0→1` + `blur 13px→0` + `contrast 1→1.04`，从极淡墨雾凝成整幅，无几何边界 |
| 300 – 1900 | **一笔勾脊**：焦墨三路径同步描出（主线 / 湿边 / 飞白），提按 `1.8→6.2→1.8px`；笔尖点随脊线移动，末 12% 抬笔 |
| 380 / 480 / 560 | 落笔溅墨三点，各延迟 0…130ms |
| 420 – 1540 | 底部一条墨线自中心向两侧长到 260px |
| 1150 – 3100 | 三只飞鸟自右向左掠过（起点不同高度 / 速度 / 大小），双翼绕中轴 ±9° 扇动，带洇边 |
| 1450 – 1970 | 「高山流水」四字逐字上浮（每字错 120ms，520ms，blur 1→0） |

| 4000 | **收尾开始**：题字 / 谱线 200ms 退净 |
| 4030 – 4550 | 画卷整体 `translateY 0→-64px` + `opacity 1→0`（easeInOut），推近比 1.05→1.00 |

总计 **≈ 5.06s**；其中纯开屏 4.0s（与网易云 4.30s 同量级）、过渡 0.84s。

## 三、关键设计口径

- **不用 mask 揭示**：圆 mask 读成聚光、横带 mask 上缘像 wipe，均弃用。改为"透明度 + 模糊 + 对比度"三属性凝墨，画面无任何几何边界。
- **收尾不再"卷成横幅"**：横幅下缘会出现一条生硬直边（读成切块），已弃。改为整幅缓升淡出。
- **勾脊路径取自真实画**：`ridge_v52b.py` 在 390×844 cover 图上逐列找首个 `L<118` 墨像素提取，主峰 (183,398)，脊线 21 个采样点，`ridge_debug.png` 已叠线核对。
- **飞鸟不整块平移**：每只由两段曲线 SVG 组成，绕身体中轴反向旋转实现扇翅；不是两张图来回切换。
- **谱线两端渐隐**：`mask-image` 17%→25%、75%→83%，避免两端出现"小方框"。
- 舞台 390×844；纸 `#F8F4EC`、墨 `#2A2622`、朱印 `#B4453A`；字体 `Kaiti SC / KaiTi / STKaiti / SimSun`。

## 四、落码时要注意（Compose 侧）

1. `SPLASH_MIN_MS` 需覆盖到 4000（纯开屏），**过渡不占这 4s**；把 520ms 淡出 + 340ms 首页浮现交给页面级过渡，否则又变成"4s 里塞收尾"。
2. 勾脊用 `Path` + `drawPath` 分段描线（`progress` 驱动），不要用 `Canvas` 逐帧重绘整条 —— 217 个点每帧重建会掉帧。
3. 飞鸟两段曲线用 `Path` 画 + `rotate` 变换，扇翅相位用 `sin`，与位图墨色 `alpha .80`、`blur .5px` 对齐。
4. 谱线 / 音符坐标必须成组维护：`staffWidth`、`noteX` 由同一组常量派生，任一处改宽度都要同步。
5. 灰度实测：`splash_ink.webp` 山脊 `peak=(183,398)`（390×844 cover、左对齐），改动裁切方式后要重新量。
