## JZ的音乐助手 v2.1.80：听歌识曲（方案 A · 最简闭环）

**这版做了什么**
- 新增「听歌识曲」：对着正在放的歌听 10 秒 → 认出歌名 / 歌手 → 自动接现有搜索链路，点结果即可播放。
- 入口两处，按你指定的位置：
  1. 首页 **搜索框之下、「编辑精选」之上** 新增一条「听歌识曲」栏（纸底墨线 + 朱砂点，点一下即开听）。
  2. 播放页 **右上角三点菜单** 新增第三项「听歌识曲」（在「桌面歌词」「查看歌词 / 封面」之后）。
- 识曲界面为全屏墨色压场 + 纸签面板：同心墨圈随环境音涨落、中心朱砂点，"正在聆听 · 还能听 N 秒"→"正在辨认"→出「歌名 / 歌手 · 专辑」，按钮「再听一次 / 去播放」。

**实现口径**
- 复用酷狗识曲：`gateway.kugou.com/fingerprint.service/v1/music_trackid_mulit`，上传 **8kHz / 单声道 / 16bit PCM（10 秒，160,000 字节）**，签名带 body（salt 与取词链路同一个）。
- 采集只在内存里，不落盘、不留存；新增 `RECORD_AUDIO` 权限（首次进入才弹授权）。
- **开听时会自动暂停本机播放**——否则麦克风录到的就是自己正在放的这首，识曲必然错成当前歌曲。识别完不自动恢复播放，由你点「去播放」或回悬浮条续播。
- 识别结果交给现有 3 平台搜索，沿用原有去重/换源/兜底，不新增音源。
