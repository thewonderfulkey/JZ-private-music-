## JZ音乐助手 v2.1.70（vc128）测版

本次改两处，正好对应你刚反馈的两条。

**1）正常播放时底部还挂「暂无可用的播放源，正在换源重试…」**

这是确定的 bug：换源重试轮到第 2、3 轮时先挂上了这句红字，但重试成功、歌已经正常起播后没把它清掉，只有重新进入取流才会清。所以会出现「歌在唱、红字还在」。本版改成：任何一次成功起播都立刻清空该提示。

**2）只有前台打开 App 才切歌（后台、息屏都不切）**

是网络被系统限制导致的，不是网络模块本身坏了。原来的链路是：上一首播完的那一刻才去联网解析下一首的播放地址——退到后台或息屏后，系统限制应用联网，这一步就失败，只能一直等网络；一回到前台网络立刻放开，于是看起来就是「打开 App 才切歌」。

本版把联网这一步挪到前面：**前台有网、上一首还在唱的时候，就把下一首整首下载到本地缓存**，播完直接从这个本地文件起播，切歌那一刻不再需要联网。顺带修掉一处死锁：等网络恢复的续播，上一版要求「屏幕必须亮着」，息屏后就永远等不到，现在只要有网就续播。

**复测建议**

- 用列表循环，连续放 3～5 首，中途退出到后台、再试息屏，看是否每首都自动切。
- 若某次还是不切，请到「设置」最下面把「播放日志」截图发回来。日志里出现 `prefetch done` / `play cache key=` 说明下一首已缓存命中；只有 `prefetch fail` 才说明那首要另找原因。
- 设置页「息屏连播 → 去允许」建议点一下，把本应用加进电池优化白名单，后台联网会更宽松。

**说明**：随机播放模式下一首不可预测，暂不做预取；单曲循环与列表循环已覆盖。
