**JZ 的音乐助手 v2.1.54（versionCode 112）**

针对你这次提的两条，逐帧看完新录屏后找到的都是同两个点，改法如下。

**① 刚点开那一帧「遮住了但没有完全遮住」**

录屏逐帧（0.90s / 1.00s）显示：那一帧其实是**系统启动画面**，不是我的动画首帧——Android 12+ 会在 `windowBackground` 之上再叠一枚 App 图标，展开时是纸色圆角卡片，卡片外四角和状态栏还看得见桌面壁纸。

- 启动画面底色改成纸色（`jz_paper`），图标换成**全透明**（`splash_blank`），图标动画时长 0，窗口进场动画也去掉；
- 动画首帧同步清空：原来"远山雾带一条"是一上来就贴着的，改成 200→1200ms 渐显；山体湿边的前缘起点从 x=50 归到 **x=0**。

结果：点开就是**整屏一张空白纸**，没有图标、没有卡片、四角不露桌面，然后墨从纸的左边一点点长进来。

**② 收尾渐变太长、形式不合适**

录屏 6.07→6.57 那 0.5 秒是各层一起做整屏 alpha 淡化，也就是"整屏漂白"，确实既长又不像动画。

- 删掉全部 `(1 - vf)` 叠乘（11 处），不再整屏淡化；
- 换成**音符放大**：墨满时先浮出一枚纸色音符（约 0.2s 露头），再把这枚音符放大到盖满整屏（约 0.28s），首页从音符的形状里被"让"出来；
- 收尾总时长约 **0.3s**（上版 0.42s + 等待）。

1. 冷启动第一帧：点开即整屏空白纸——没有卡片、没有耳机图标、四角/状态栏不露桌面壁纸。
2. 前 1.2 秒：纸面从左边长出山体，不再有"一上来就贴在那里"的东西。
