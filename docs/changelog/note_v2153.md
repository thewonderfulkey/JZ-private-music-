# JZ 音乐助手 v2.1.53（versionCode 111）— 开屏动画真机修复

> 针对周亚楠真机录屏的三条反馈逐条改了根因，不再调美术参数。

## 一、录屏取证（先确认"到底是什么不一样"）

把 8.47s 的录屏按帧取出来，在飞瀑区做 2.4× 放大 + 像素探针，结论是**裁形状的那一层在真机上失效了**，不是画得不好看：

| 位置 | 设计应有的样子 | 录屏实测 |
|---|---|---|
| 水练中心 (300,520) | 墨色水丝在白色水练里落 | RGB≈[246,233,230]，**近乎纸白**（水练里没墨） |
| 遮罩外右侧 (370,520) | 纸/山石，不该有水丝 | **有墨**（水丝溢出，铺满右侧整列） |
| 水练轮廓 | 水丝被裁在水练形状内 | 一条**纯白实心水练**贴在画面上 |

即：应当"按形状裁"的遮罩，在本机运行时把**遮罩的透明区画了出来、把不透区擦掉了**——方向反了。所以整片裸纹理铺满，纵向纹理又被读成"水往上走"，山下水面也被竖丝压成一张栅格。这解释了为什么预览一直好看、真机完全不一样。

## 二、三条反馈 → 三个修法

1. **"水流从下往上走，方向错了"**
   现在飞瀑改成**离屏位图 + `android.graphics` 的 `DST_IN`**：每帧在一张 312×552 的离屏画布上，先用增值相位向下铺水痕瓦片（`y` 递增，`(t*0.340)%208` 与副层 `(t*0.620)%208` 错速），再按水练形状裁一次，最后一整张贴上去。**方向由 y 递减改回 y 递增（真的往下坠）**，裁剪不再依赖 Compose 的混合模式。

2. **"与设计好的动画完全不一样"**
   - 白色水练：消失（遮罩只在离屏画布内生效，不再作为可见白图贴上屏）。
   - 墨丝溢出山石/水面：消失（水丝被裁在水练形状内，不再铺满右半边）。
   - 山体"长出来"：原来是自右向左收，方向也是反的；现在**自左向右**（x=50 → 520，1.44s），前缘 46px 用纸色渐变压进纸里，山脊三株墨树跟着一起长。
   - 远山雾带：去掉遮罩，只按 y330→374 这一条硬裁，常驻不参与生长。

3. **"山下的河流线条有点太多了，没有简易美感"**
   原来 46 笔横纹铺满整个水面 → 现在是**12 笔稀疏短横纹**（新烘 390×140、导出 3 倍 1170×420，笔触为渐细椭圆叠加 + 轻起伏 + 柔化）。上缘 36px 渐隐到 0.66、再补到 1.0、下方轻收，**渐隐直接烘进 alpha**，不再叠遮罩。落码只画两张（横向极慢游走，不再往上飘）。
