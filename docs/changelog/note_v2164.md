## JZ 音乐助手 v2.1.64（下载链路补齐）

**这次改的是下载**，两条缺口都补上了：

**① 320k / 128k 也自动换源**
以前只有选「无损 FLAC」才会换源，320k 和 128k 基本是"本平台拿一条就完事"。现在三档走同一条链：
本平台后端 → 同曲跨源换源（同歌名同歌手，排掉 live/翻唱变体）→ 通用搜索式后端兜底，一路换到拿到所选档为止。

**② 下完按文件大小校验是不是真的那档**
每个候选文件下完落盘后，都重新读一遍：
- 容器头（flac / wav / mp3 / m4a / ogg / aac）
- 文件字节数 ÷ 歌曲时长 → 真实码率

判据：无损 = flac/wav 容器或 ≥600kbps；高品 320k = 非无损容器且 256–600kbps；标准 128k = 非无损容器且 48–255kbps。
不符合就直接删文件、继续换下一条（最多试 3 条）。三条都不符才如实降级保存，并在下载列表里写清「所选 vs 实得」和原因。
另外加了一道截断防线：实收不到服务端声明长度的 95% 就判定文件不完整，不入库。

文件名也随之改了：按实得容器给扩展名，不会再出现 `.flac` 里装 mp3 的情况。
