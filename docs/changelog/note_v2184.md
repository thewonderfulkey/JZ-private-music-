## JZ的音乐助手 v2.1.84 · 听歌识曲收口

上一版你实测后提的四条，这一版全部落地。**版本号 2.1.84（versionCode 142）**，包名不变，覆盖安装即可。

### 1. 聆听/辨认中再点麦克风 = 取消这次识别
上一版点了确实没反应——根因是麦克风点击分支写成了 `if (!listening) start()`，聆听中这个事件直接被吞掉，没有任何提示。
现在改成：**聆听中或辨认中再点一次，就是取消**——立刻停采集，那段音频直接丢掉，**不做识别、不拿已录片段凑数**，页面回到「点一下麦克风，开始听」。
为了让这条能被发现，文案也补了两行：聆听中显示「还能听 N 秒」+「再点一下麦克风，就取消这次识别」；辨认中显示「比对曲库中，稍等；再点一下麦克风就取消」。

### 2. 点历史条目 / 点「播放」立刻弹播放页
上一版是先检索、再取流、最后才滑上播放页，点完要等好几秒。
现在顺序反过来：**先用一条占位曲目把播放页顶出来**（页面显示「正在解析音源…」），检索和取流全部放到后台；挑到候选就原地换成真曲目开始播，队列仍是同曲前六条。
两个细节：占位期间不会拿假 ID 去打三个歌词接口白等；你中途按返回收起播放页，它不会把你拽回来（只有占位页还挂着时才自动替换）。

### 3. 识曲历史退出 App 也保留（50 条）
按你的口径，条数跟底层栏「历史」一致——**保存 50 条**，存在本机 SharedPreferences（`rec_history`），每次识别成功即时落盘，退出 App 再进来还在。列表可滚动，同歌同歌手自动去重。

### 4. 右上角「听十秒」改成可配置按钮（原位置）
位置不动，形态从一个纯文本变成一枚墨线小按钮「听 N 秒 ▾」；点开在下方弹出四档：**5 / 10 / 15 / 20 秒**，当前档加粗并带一枚朱砂点，选完立即落盘，下次进页还是这档。
聆听/辨认中按钮降到半透明、不可点（中途改时长会和已采长度对不上）。
四档不是我拍脑袋定的：把样曲分别切成 5/10/15/20 秒、按 8k 单声道 16bit 打酷狗指纹接口实测，**四档全部 `error_code=0`、都返回 5 条候选、都识别为「晴天 / 周杰伦」**，所以放开这四档是安全的。

### 顺手修掉的一个真 bug
你 23:10 那张截屏里，底栏第 2 格「识曲」的小字几乎看不见——像素扫描确认标签行没有深色像素，是**白字写白纸**：图标和标签共用一个 `color`，选中态给的是纸白色，而墨印只盖住 44dp 图标区、标签落在纸面上。这一版标签改回墨色，选中项六个字都看得清。
