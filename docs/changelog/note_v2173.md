## 音乐助手 v2.1.73（vc131）· 平板/横屏自适应改版

按你给的两段实机录屏（手机 540×1172、iPad 800×1280）逐帧比对后改的三件事，全部以**手机竖屏为基准**：

**① 开屏：8 处绘制全部从"横纵各拉一次"改成"按屏高等比"**
- 原因：原来按 390×844 设计稿直接铺满画布，iPad 上横向比纵向多拉约 **35%**，山体被压成一条横向扁带、上下各留一大条纸白，题字与朱印相对屏幕显得极小。
- 改法：`k = 屏高 / 844` 等比缩放 + 墨图左对齐（633 宽的溢墨，窄屏裁右缘、宽屏居中）。山水、题字、跳过按钮、音符收尾洞口共用同一套映射，字与山不会再错位。
- 手机观感零变化：手机上 k 仍等于原来的裁切量，构图与节奏一模一样。
- 顺带修好了超宽屏：以前横屏开屏是被拉扁的，现在按屏高等比、两侧留纸边。

**② 平板播放页：画心不再被 392dp 锁死**
- 原因：旧版画心边长取 `min(档位常量, 白框宽, 可用高)`，平板上前两项是常量，屏幕再高也不放大，余量全堆到底部 → 你看到的"底部大片空白"。
- 改法：平板档取消画心上限，只受真实宽/高约束；列宽 720dp 上限内随屏放宽；段落之间按权重分配弹性，让封面→题名→进度→控件→音源纵向铺满。
- iPad 竖屏实测口径（数值核算）：画心 392 → **644dp**，白框占屏宽 **84%**，底部不再有 22–30% 空白。

**③ 横屏统一成左右式（手机 + iPad 同一套）**
- 左边：白框封面，**双击出歌词**（再双击回封面）；右边：题名/歌手 + 墨线进度 + 五件控件（循环·上一·朱砂暂停·下一·下载）+ 状态行 + 音源行。
- 手机横屏原来封面整块消失（矮屏回退手机档、画心被可用高压到接近 0），现在不再走那条路径。
