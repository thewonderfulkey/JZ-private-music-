### v2.1.31 悬浮栏四钮按压反馈修复

**问题**：v2.1.30 安装后，悬浮栏的收藏 / 上一曲 / 暂停 / 下一曲四个钮点了没有任何反馈（也无缩放压暗）。

**根因**：v2.1.30 为了修「左右切歌点不动」，在悬浮栏最上层加了一条覆盖全宽的手势通道。它是容器最后一个子元素，也就是最上层；Compose 的点击命中测试只会把指针事件交给最上层命中的那个元素，下层四个钮的点击处理从此收不到手指按下的消息 —— 按钮既不进入按压态，也不响应点击。封面与歌名区在左半边同样被吃掉。

**修法**：

1. 整条手势通道彻底移除，不再在按钮上方放任何浮层。
2. 四个钮的热区改为「按分区连续铺满」的矩形：纵向取按钮行 0.18~0.82 高度（约 50dp），横向首尾相接覆盖 0.50w~0.952w，每个热区宽 44~45dp、彼此不重叠也不留缝，任意落点都归属唯一一个钮，不会再出现点在钮边「落空」。
3. 四个热区继续复用全站那套 `inkClickable`，与点击歌曲 / 歌曲行是同一份实现：按下即时缩放 0.93 + 墨色压暗 26%，抬起 120ms 回弹、压暗 220ms 淡出。
4. 视觉零改动：收藏/上一曲/下一曲图标仍 24dp、暂停朱砂实心圆仍 44dp、圆心位置不变，只有热区变大。

**版本**：2.1.31 / versionCode 89，「设置-关于」同步。
