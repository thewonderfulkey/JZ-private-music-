## JZ的音乐助手 v2.1.48（下载音质修复）

**要解决的问题**：选了「无损 FLAC」，点下去却提示"没有无损、已自动降级"。

**两个根因**

1. 预检和挑源是两套口径。弹层打开时只判断"有没有源"，从不看源的音质——只要有一条 128k，无损档就会亮；点下载时又发一次独立请求重新挑源，而且挑源器"列表非空必返回一条"。三次叠加，这个矛盾必然复现。
2. 后端在虚标。实测 oiapi 网易的 lossless / exhigh / standard 三档返回的是同一个 128k mp3（字节数完全一致）；cyapi QQ 恒给约 98kbps 的 m4a，却标成「高品 320k」。

**这次改了什么**

- **音质按文件实际内容标注**：取流时读前 4KB，按容器头（FLAC / MP3 / M4A / WAV）加上字节数除以时长反算真实档位，不再信接口自报。顺带修掉「.flac 后缀里装 mp3」的坏文件。
- **下载前预检整段去掉**（按你的要求）：三档都能点，点了就直接去解析。
- **新增跨源换源**：本平台拿不到目标音质，就按「同歌名 + 同歌手」搜同曲，逐个换源直到拿到。允许换到其它平台——QQ 的歌因此可以下到网易通道给的真 FLAC。
- **版本防线**：换源时排除 live / 现场 / 综艺 / 翻唱版；原唱要找替身时，时长差超过 3 秒一律否决。
- **全都拿不到目标档**：按可得的最高档下载，提示里写明「该曲最高只有 320k，已按此下载」——不静默降级，也不直接失败。

**实测佐证**（本机 10-29，只认容器头，不认接口自报）

- gdstudio 网易 br=740 → FLAC，809~1490kbps，23.5~48.6MB ✅
- oiapi 网易 三档 → 同一个 128k mp3，字节数一致 ❌
- cyapi QQ → m4a 97~98kbps ❌
- 妖狐 酷我 → FLAC 26.7MB / 48.4MB ✅

**麻烦装完复拍两点**

1. 随便找几首歌，把三档各点一次，看提示里说的档位和实际下到的文件后缀是否对得上。
2. 拿一首 QQ 的歌点无损：如果成功，提示会写「已换源：网易·xxx」——这就说明跨源取到真无损了；如果只拿到 320k，会明确告诉你最高只有 320k。
