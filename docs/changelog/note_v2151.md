# JZ 的音乐助手 v2.1.51 — 开场动画时长对齐网易云（纯开屏 4s）

## 这一版改了什么
上一版 v2.1.50 实机录屏逐帧量出来：点图标 2.35s → 2.40–3.07s 系统底（0.67s）→ 水墨首帧 3.07s 上屏 → **3.5s 就已经进了首页**，纯开屏实际只被看到约 **0.5 秒**。

两个原因，这版都修：
1. **计时起点错了**：开场计时从 Compose 组合时就起算，而画面要过几百毫秒才真正上屏，1.2s 预算里约 0.6s 是"看不见"地跑掉的。现在改成 **等首帧真正上屏才起表**（`withFrameNanos` 两帧对齐后再计时）。
2. **最短时长形同虚设**：首页一直垫在开场覆盖层下面同时组合，"首页已就绪"信号在开场刚开始就为真，旧逻辑第一圈判断就直接退出、60ms 后开始收束，`SPLASH_MIN_MS` 从未生效。现在改成 **必须满 4s 才收束**，就绪信号只用来决定"要不要多等"（4s 未就绪最多等到 6s）。

## 4s 内的新节拍
- 0–0.78s：纸 → 画淡入
- 0–4.0s：画卷极缓推近 1.10 → 1.03（全程在动，不留站桩段）
- 0.30–0.62s：品牌行 + 「跳过」浮出
- 0.90s 起：题名四字逐字上浮（每字间隔 110ms，末字 1.75s 收齐）
- 1.85–2.25s：「知音常在」淡入
- 2.35–2.58s：朱印落下
- 0–4.0s：墨线匀速走到 96%，**首页真就绪才补满最后 4%**（线满 = 确实可以进首页）
- 4.0s：收束成顶部横幅（260ms）+ 化开进首页（150ms）
