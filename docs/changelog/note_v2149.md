### 为什么之前下到 2.97 MB

旧代码的换源逻辑是"问候选自己平台的后端"。QQ 的歌只问 cyapi（恒 97k m4a），网易的歌只问网易后端——**唯一稳出 FLAC 的妖狐，只有候选是"酷我条目"时才会被叫到**。而酷我搜索对这批歌返回的全是伴奏/DJ/13 秒片段，被过滤后一条不剩。于是链路一路空手，落到 cyapi 的 m4a。

### 这版改了什么

- **下载无损时，第一轮拿不到就直接走通用通道**：妖狐是"按歌名+歌手"取流的，跟歌来自哪个平台无关，任何平台的歌都能喂给它。所以 QQ 的《外婆》现在会直接拿到 27MB FLAC。
- **只对无损请求启用**：妖狐恒返回 lossless，你要 128k 时不该收到 40MB 的 FLAC。
- **加版本防线**：妖狐返回的标题若不是裸名（如"外婆 (Live)"），当场拒绝，绝不下现场/伴奏/翻唱。
- **体积判定加固**：服务端忽略 Range 回 200 时用 Content-Length 兜底（原来会判成 0 码率→一律 128k），并且只读文件头 16 字节，不再整个吃下几十 MB。
- 下载前的校验（第二段）已整段删除，弹层点了就下。

### 体积判据（你可以直接照这个验收）

- 96k m4a ≈ **2.6–3.8 MB**
- 128k mp3 ≈ **3.7–5.3 MB**
- 320k mp3 ≈ **9–12 MB**
- 真 FLAC ≈ **24–55 MB**

下载目录里出现 24MB 以上、扩展名 `.flac` 的，就是真无损。
