## v2.1.60：热门行改与「猜你喜欢」同款 + 切 Tab 叠印修复

**① 热门音乐行改成和「猜你喜欢」一样**
对着录屏逐帧比了两处的实际差异（原热门：左侧 `01–08` 序号列 28dp + 44dp 封面 + 6dp 行距；猜你喜欢：48dp 封面圆角 10 + 8dp 行距 + 15sp 歌名），现在统一成猜你喜欢那一套：

- 去掉序号列（排名数字不再显示）
- 封面 44 → 48dp，圆角 8 → 10
- 行内上下留白 6 → 8dp，行高与歌名、歌手、右侧播放三角的位置完全对齐
- 副行仍是歌手（猜你喜欢的副行是「因为你在听 ××」，热门没有推荐理由字段，不硬凑）

**② 切底部 Tab 时的 bug——新旧两页叠印**
录屏 11.10–11.30s 这一段是证据：切「首页 → 收藏」的 250ms 里，首页的「发现音乐」标题、返回箭头、8 条榜单，和收藏页的「我喜欢的音乐」标题、心形空态、「还没有收藏的歌曲」同时画在同一屏上，底栏墨印正在滑动；11.20s 那一帧两页各透一半，看起来就是排版错乱。

根因：各 Tab 页自己是透明底（纸色来自全局 `AppBackground`），横向滑动时新页盖不住旧页。这条滑动一直存在，此前被「整幅山水 wipe」遮着，v2.1.59 按「首页 0 处山水」把 wipe 停用后，叠印就露出来了。

修法：把纸底抽成 `PaperBrush`，每个 Tab 页各铺一层不透明纸底。新页滑入即完全盖住旧页，转场回到「新页推入」而不是「两页叠印」。

**③ 录屏里还发现一件事，需要你定**
放大 06.50s 的「刀马旦」「白桦林」可以看出来：歌名仍是手写楷体的笔画，不是思源黑。App 里歌名已经指定了系统无衬线，这说明手机系统的「字体」被换成了手写体——安卓的 sans-serif 会跟着系统字体走，App 管不到。要在任何手机上稳定显示无衬线，只能把中文字体内置进 APK（体积约 +4~7MB）。这一版没动，要不要下一版内置，你说一声。
