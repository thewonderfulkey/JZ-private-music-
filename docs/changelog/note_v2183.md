## JZ的音乐助手 v2.1.83

本次两条反馈都落地：**识别结果直接起播** + **识曲独立成页、首页复原**。

### 1. 识别出来后点「播放」= 直接起播
- 以前点「播放」只是把「歌名 歌手」丢进首页搜索框，人被甩到搜索结果页，还得再点一次。
- 现在点「播放」在后台按「歌名 + 歌手」检索（与搜索同一套适配器），
  先按「同歌名 + 同歌手」收窄，退化为「同歌名」，再退化到全池；
  用录音室原唱得分挑一条（会压 Live/节目版/合唱版），**直接开始播放并进播放页**。
- 队列取同曲候选前 6 条，播完能继续听；按钮期间显示「正在起播…」防连点。
- 一条都搜不到时才提示「听出了《…》，但这几平台都没给出可播的条目」，不会静默失败。

### 2. 识曲从首页搬到下层栏，独立成页
- 底部导航从 5 格变 6 格：**首页 / 识曲 / 收藏 / 下载 / 历史 / 设置**（识曲在首页右边）。
- 首页恢复原样：原搜索框与「编辑精选」之间那条识曲栏已撤掉。
- 新页 UI（见附图）：题字「听歌识曲」+ 发丝线 → 一枚圆形麦克风（**整页只有这一处可点**，
  外围三道墨圈随响度呼吸，听的时候会涨）→ 阶段文案（还能听 N 秒 / 正在辨认）→
  下方内容区：结果纸签 +「再听一次 / 播放」两个按钮 + 其他版本列表；没结果时显示「最近识过」，
  没有记录时显示第一次用的说明与三条提示。
- 进页不会自动录音，**点麦克风才开始听**；离开这一页（切 Tab 或返回）自动收掉采集，不在后台留录音。
- 播放页三点菜单里的「听歌识曲」保留，点它会跳到这一页并直接开始听。
