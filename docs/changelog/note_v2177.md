# v2.1.77 桌面歌词「元素化」改版

这版一次把你提的三件事都做了：**（1）不再省略号截断、（2）样式不再只是"居中"、（3）按 QQ / 网易云 / 酷狗的桌面歌词加元素（全部都要）**。

## 一、截断：从机制上消掉省略号

先量了根因（不是没生效）：上一版栏宽 274dp、左右各 16dp 内边，可用只有 242dp；霞鹜文楷 17sp 下**一行最多约 13 字**，截图那句 14 字就被 `TextUtils.ellipsize` 补了「…」。

这版直接改机制，不是调参：

1. **栏宽 274 → 308dp，左右内边 16 → 10dp**（可用 288dp，比旧版多 46dp）；
2. **彻底移除 ellipsize**，改成"按当前句实测宽度自动降字号"：放得下就单行，放不下按 3% 一档往下退，**下限 0.72 倍（≈13.5sp，可容 21 字）**；
3. 0.72 倍仍放不下才**折行**（优先断在空格 /「，」「、」「。」处），当前句最多 4 行、下一句 2 行；
4. **栏体高度随行数长高**，窗口同步改高度，工具条展开时栏体不动、向下长。

设计阶段按同一口径算过四档：17sp/内边16 → 13 字；17sp/内边10 → 15 字仍截；15.5sp → 18 字；13.5sp → 21 字全显示。现在 308dp + 自动降档把"截断"这条路堵死了。

## 二、样式：加了四个看得见的元素

1. **逐字染色**（对齐 QQ 音乐 / 酷狗）：整句先铺淡墨，唱到哪压深到哪，未唱留在 `#B0A898`；
2. **底边进度线**：先画 10% 淡槽，再画实线走当前句进度，距底 4.4dp、左右各收 10dp；
3. **右上角小锁**：锁住后不再响应拖动（看视频不误拖），但**轻点仍能开工具条**——否则锁上以后就解不开了；
4. **工具条**：轻点纸签浮出 6 格 7 动作 —— `上一句 / 暂停·播放 / 下一句 / 字号 A- A+ / 锁定 / 关闭`，按钮间 0.8dp 分隔线，**3 秒无操作自动收起**。

换句仍是 300ms 上下 10dp 交叉淡入；逐字染色与进度线每 200ms 随播放推进（暂停时整句转灰、「‖」跟在字后）。

## 三、三主题 + 五档字号

- **素纸** `#FBF7ED` / **旧黄** `#F2E5C4` / **夜墨** `#24211D`（浅字 `#F0EADA`）；
- 描边、上缘压墨线、进度槽与实线全部由"纸色 × 墨色"按比例混合生成，换主题时不会冒出写死的黑框；
- 字号 **-2…+2 五档、每档 8%**，与自动降档叠加（你定的档位是上限，长句仍会自动再降，保证完整）；
- 设置页新增**纸色三选、字号 A-/A+、锁定状态**三行，全部持久化（`dl_theme` / `dl_font` / `dl_lock`）。

## 六、口径提醒（要改一句话的事）

- **上一句 / 下一句** = 跳到相邻歌词行的时间点，不切歌；**关闭** = 关掉桌面歌词开关（等同设置页置 off）。如果你要的是切歌、或"关闭只收工具条"，说一声就改。
- **锁定时仍可轻点开工具条**是我补的（原设计锁上点不动，等于再也解不了锁）。
- 关于"只看到居中、没看到更多样式"：截图实测量过你装的是新包（栏高 64dp、宽 272dp、纸色 (252,247,233)、圆角 8dp 全对），问题是 18% 墨线 + 近白纸色在花壁纸上太弱 —— 这版把元素直接加进栏里了。
