## v2.1.90 已发出：恢复只标「原唱」

**上一版错在哪**
上一版把「录音室版」当成独立小印，判据是「歌名有没有 (Live)/(DJ)/伴奏 这类后缀」。这首《我们都一样》的同曲翻唱几乎全用裸歌名，于是每一行都被判成干净版 → 满屏「录音室版」。是我这条判据设计错了，跟曲库数据无关。

**现在只标一处「原唱」，按我们定下的 D 口径**
1. 识曲命中的本身就是录音室版 → 按识曲歌手标（这种情形可信）；
2. 命中的是综艺／现场／改编版 → 用「同一位歌手有 ≥2 张不同的正式专辑、且这几条时长互相 ≤3 秒」推断：同一版录音被反复收录才算原唱。专辑名就等于歌名的同名合集（橘子妹、胡小斐、解昕怡这类）不算正式专辑；现场／综艺专辑也不算；推不出来就不标，宁可不标也不标错。

**实测结果**
真实池子 100 条（QQ 50 + 网易 50）、同曲 91 条，判定为原唱的只有张杰：
- 网易《明天过后》302s
- 网易《One Chance 新歌+精选》303s
两条互证是同一版录音。橘子妹／胡小斐／解昕怡／周延英／曹轩宾／棉花糖／王理文均不标。

**顺带修的一处**
识曲改为先读指纹接口返回的多条候选取优，优先取非综艺／非改编那条（原来直接吃第 1 条）。
