## JZ的音乐助手 v2.1.85 已出包

本轮按你 23:33 发的录屏 + 截屏改了三条，都已进包，APK 在下面。

**① 识别对、播放却不是同一首 → 现在「歌名 + 歌手」都要对上**
录屏第 4 秒是直接证据：识别结果是《IVORY TOWER》· 澤野弘之 / SennaRin / 龙族 动画OST，但起播的悬浮栏里是 Blackmore 唱的《Ivory To…》。
原因是上一版为了"一定能播出来"，把匹配一路放宽到"只要歌名对"——于是同名不同曲（别人翻唱、别的版本）就被当成同一首起播。
现在改成：同歌名 **且** 歌手的任一位命中（"甲、乙、丙"这种多歌手串会拆开比），才起播。
如果曲库里只有别人的同名版本，就不硬播了，结果卡上写明"这一位歌手没有可播条目"，并把版本列表直接摆出来给你挑。

**② 结果卡新增「其他版本」按钮**
点一下按歌名重新检索各平台，收回同名的其他歌手版本（同一位歌手只留一条，最多 12 条）：
- **原唱（= 识别到的这位歌手）排在最上方**，并标一枚朱砂「原唱」印；
- 其余按平台返回顺序往下排，标 歌手 · 平台；
- 点任意一条直接起播，队列就是这份版本列表，可以一路听下去。
顺带把同一次指纹识别给出的其他候选放在「同批候选」里，不占「其他版本」的位置。

**③ 播放悬浮栏不再压住「最近识过」最后一条**
这是边距问题：内容区底部没有给播放条留位置。现在「最近识过」列表底部补了 84dp 让位（播放条高 ≈ 72dp，留一圈余量），
滚到最底最后一条整条都在播放条上方；结果卡区域同样补了让位，内容长了也能滚。

**④ 播放缓存（你要的那套）**
- 取流器一拿到歌，就把这一首整首缓存到本地；
- **缓存进度直接画在播放进度条上**（进度线底下那条淡墨带，越长说明缓存越多）；
- 整首落盘后自动把播放源切到本地文件，**从当前位置接着放**——之后拖动进度条不再发网络请求、不用重新搜歌重新取流；
- **只缓存当前这一首**：切歌即删、这首播完即删、App 启动时清掉上次残留；缓存按磁盘文件走，不在内存里压一整首歌。
