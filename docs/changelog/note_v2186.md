## JZ的音乐助手 v2.1.86 —— 识曲结果页重做

**这一版只改「识别出结果后」的界面，功能与 v2.1.85 完全一致**（严格歌手匹配、其他版本、悬浮栏让位、播放缓存都保持原样）。

### 上一版的问题
结果卡是一张「细边框 + 纸色渐变」的矩形，下面三块矩形并排堆着（再听一次 / 播放 / 其他版本），像表单；歌手和专辑还被挤成一行。

### 这一版
1. **主结果 = 一张方角纸签**：纸色底、1px 淡墨边、方角（不做圆角），顶上「识 所 得」眉标 + 一根短墨线 + 右上角朱砂小印「识」。
2. **歌名 26sp 霞鹜文楷**，下面一根短墨线断句；**歌手与专辑分成两行**，专辑单独走《》书名号，不再挤一行。
3. **只留一个实心块**：整宽 44dp 墨底「▶ 播放这首歌」。其余动作降为文字链：「再听一次 ｜ 其他版本 · 4 条」，不再并排矩形。
4. **列表标题改成书页式**：`其他版本 ———— 4 条`（标签 + 贯通细线 + 条数）；`同批候选` 同款。
5. **版本行**：原唱那一行左侧加一道朱砂细签，歌名后挂 9sp 朱砂「原唱」细框印，行间只留发丝线。
6. 同名但歌手对不上时，说明文字也改成「朱砂细签 + 说明」，和红色错误框区分开。
7. **结果态把麦克风缩到 0.72**（这一项是本版新加的版面决策，为的是让下面多露出一行版本），听歌过程中恢复原尺寸。
