## JZ 音乐助手 v2.1.50：开场动画上线

**这一版只改一件事——冷启动那段约 1.67 秒的纯白空屏，换成山水水墨开场。**

打开 App 现在的过程：

1. 纸色起（窗口底色已同步改纸色，白屏从根上没了）
2. 真实纸本水墨画淡入，同时由 1.10 回缩到 1.04（纸→画）
3. 「高山流水」四字逐字上浮，「知音常在」压一行，朱印落下
4. 底部细墨线按**真实启动进度**走满，满格即刻收束（不干等固定时长）
5. 画卷收成顶部横幅（底部圆角 + 底边溶解），化开就是首页，中间没有硬切

时长绑加载：**最短 1.2s / 首页一就绪就收 / 最长 2.2s 兜底**。右上角有「跳过」。

**跟上一版路数上的不同：**
- 画面是真图素材（1080×1440 webp，114KB），不是代码画的假水墨
- 动画全部是 UI 位移、缩放、高度收束，没有手写 SVG 逐层揭示
- `windowBackground` 同步改纸色 `#F7F5F0`，冷启动第一个像素就是纸

**验证提醒（重要）**：本机没有真机也没有模拟器（adb 一直空），静态验证过了，但观感只能靠实机。装上后请留意两点：① 收束那 260ms 横幅底边溶不溶得干净；② 低端机首帧会不会掉帧（真掉帧就说明位图还得再压一档）。
