## JZ音乐助手 v2.1.71（vc129）测版 —— 后台连播修复完整版

你复测的结果把根因钉死了：**加上电池优化白名单后，息屏/后台播完就能正常切歌**。所以不是播放链路、也不是音源接口的问题，而是系统在后台冻结了应用的联网。

## 为什么「明明连着 WiFi 也用不了网」

Android 的 Doze（低电耗模式）在屏幕熄灭、设备静止一段时间后，会对应用做两件事：冻结后台任务、暂停应用的网络访问。注意是**暂停应用访问网络的权限**，不是断开 WiFi——所以状态栏 WiFi 照旧是连着的，信号满格，但应用发出的请求会直接超时。再加上国产 ROM 的省电策略比原生更激进，往往熄屏几分钟就生效。

只有一种应用不受这条限制：被用户明确加进「电池优化白名单」的应用。你手动加了一次之后立刻恢复正常，就是这个机制在起作用。

## 这版做了什么

1. **首次打开自动申请**：App 装好后第一次启动，会自动弹出系统的「允许应用不受电池优化限制」对话框，点一次「允许」即可，之后永久生效，不用再去设置里翻任何菜单。
2. **多首缓存兜底**：前台有网时，不只是缓存下一首，而是把后面 **3 首**一起缓存到本地。就算某次系统还是把网掐了（比如白名单没给、或厂商策略更强），后台也能靠缓存继续往下唱几首，不会一首就断。
3. **设置页的「播放日志」整块已移除**，界面更干净；只有在系统明确没放行时，才会出现一行「后台连播 · 去允许」的兜底入口，正常情况下看不到。
4. 保留上一版的两处修复：成功起播清掉「暂无可用的播放源」红字；等网络的续播不再要求屏幕亮着。

## 需要你知道的一点

系统那个「允许」按钮**只能由你点一下**——这是 Android 的安全模型，任何应用都无法替用户点掉系统授权框。这是全流程里唯一需要你动手的地方，装好第一次打开时会自动弹出来，点完就再也不需要管了。

如果当时点了「拒绝」，也可以随时在系统的「设置 → 应用 → 本应用 → 电池」里改成「不受限制」。

## 复测建议

- 装好后首次启动注意那个系统弹框，点「允许」。
- 列表循环连放，退后台、息屏各试几首，看是否一首接一首自动切。
- 若仍有不切的个别情况，请说明当时是否在系统弹框上点了允许。
