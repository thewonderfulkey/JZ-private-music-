# v2.1.76 桌面歌词改版：歌词居中 + 「墨边纸签」

版本：v2.1.76 / versionCode 134　包名 com.jz.musichelper
产物：JZ音乐助手-v2.1.76.apk　29,634,383 B　MD5 `D9E7C6C085B91D9D08D3EDCA60BD2D5C`

## 一、你提的两点

1. 歌词要相对悬浮栏居中 —— 原来 `Paint.Align` 是默认的左对齐，当前行贴左边距、下一行也贴左边距，右边空一大片；
2. 悬浮栏太丑 —— 近通栏的白色大圆角块，两行字号只差 2sp（15/13），主次不分，看着像系统弹的提示条。

这两点这次一起改了。设计稿先在对话里过了「墨边纸签」这一版，按你指定的方向落码。

## 二、视觉口径（落码后的实际参数）

| 项 | 旧（v2.1.75） | 新（v2.1.76） |
| --- | --- | --- |
| 宽度 | 屏幕满宽减 32dp（≈328dp，近通栏） | **固定 274dp**（约屏宽 76%，小屏最多留 12dp 边） |
| 高度 | 88dp | **66dp** |
| 圆角 | 18dp | **9dp**（小圆角才像裁好的纸，胶囊更像 toast） |
| 底面 | `#F2FAF8F3`（半透） | `#FFFBF7ED` 纸色实底，不透明（花壁纸上也读得清） |
| 描边 | `#DED7C8` 实色 | `#2E2E2A24` 1dp 墨线（18% 透明度，只定边，不抢字） |
| 当前行 | 15sp 墨色，左对齐 | **17sp** 墨色 `#2E2A24`，**居中** |
| 下一行 | 13sp 灰色，左对齐 | **11sp** 灰色 `#8A8378`，**居中** |
| 行距 | 靠 0.35h / 0.70h 两个固定比例 | **6dp** 显式间距，两行作为一块竖直居中 |
| 暂停 | 当前行变灰 +「‖」钉在栏右侧 | 当前行变灰 `#6C655A`，「‖」跟在文字右侧、**与文字作为一组整体居中** |
| 空态 | 13sp 灰、居中 | 不变（仍居中） |

宽度取固定值不跟每句长短走，是有意的：若按内容自适应，长句短句交替时栏体会一句一缩，看起来在抖。短句时文字照样居中，只是两侧留白多一些。

字体仍是霞鹜文楷、无投影、无毛玻璃、无渐变；换行仍是 300ms 上下淡入淡出；拖动吸边、转屏比例复位全部保持不变。

## 三、改了哪几处

1. `ui/DesktopLyricsView.kt`（重写绘制层）：
   - `curPaint` / `nextPaint` 改成 `Paint.Align.CENTER`，两行各自按栏宽取中点绘制；
   - 版式从「0.35h / 0.70h 两个固定基线」改为「先算两行文本块总高，再整体垂直居中，行间 6dp」；
   - 新增 `drawPauseMark` 的组居中：先量当前行文字宽，再算「文字 + 9dp + ‖」整组宽，整组落在中线；
   - 底色 / 描边 / 圆角 / 字号按上表换新。
2. `data/DesktopLyrics.kt`：窗口宽高常量改为 `W_DP = 274f` / `H_DP = 66f`，并加 `W_SIDE_DP = 12f` 兜底（屏宽不足时最多吃 12dp 边）。
3. `app/build.gradle.kts`：`versionCode 133 → 134`、`versionName "2.1.75" → "2.1.76"`。
4. `ui/SettingsScreen.kt`：关于页版本行改 v2.1.76，「本版更新」改写为本次居中 + 改版说明。

## 五、30 秒自查（装好后）

1. 放一首有词的歌，打开桌面歌词，按 Home；
2. 看两行字是否都在栏体正中间（不再是贴左、右边空一块）；
3. 切到一句明显短的歌词（比如四五个字的行），确认它仍在正中而不是靠左；
4. 下拉通知栏暂停 → 当前行变灰，「‖」紧跟文字右侧，整组仍在正中；
5. 拖动吸边、转屏复位应当和上一版一样。

若发现哪种状态（空态 / 加载中 / 长句截断 / 暂停）没居中，把那一帧截给我，按状态单点修。
