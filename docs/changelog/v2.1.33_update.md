## JZ 的音乐助手 v2.1.33 · 搜索框落码完成

第八轮的方向已经落进代码：**搜索按钮改成太阳**。

**这一版变了什么**

- 搜索条不再是一个「圆角容器」，而是一幅渲染出来的水墨横幅（656×148，真机 328×74dp）：上半天整片天空的留白就是输入区，字直接写在画上；下半是雾里的远山和一线水面。
- 搜索按钮 = 一枚**朱砂红日**，落在右上的天空里。它不是画上去的红圆点——中心浓、边缘在两三 dp 内被纸吃掉，没有硬边，所以它属于这幅画。
- 联动沿用上一轮方案，只把印章换成日：
  - 按下搜索，红日开始**呼吸**，外面一圈极淡的光晕涨开；
  - 同时**五个墨点像鸟一样从左掠出画面**，飞出即算「找到了」；
  - 水线自红日正下方**荡开两圈**，只落在水面那一线上。
- 点条的空白处仍然展开／收起搜索历史；有词时右侧出现清空；按键盘上的「搜索」也直接搜。

**为什么这样**

前七版被判「线稿」「塑料」「像贴纸」，病根是笔触用等宽线画、且控件是「容器」。这一版的画是生成出来的位图，字、日、鸟、水都长在画里，不再浮在容器上。

**已知缺口**

- 本机无设备，未做真机冒烟（按你的要求不出 adb）。红日在实机上的观感与呼吸节奏需要你装上确认。
- 太阳取的是朱砂红（复用主题里的 `heartOn #B03A2E`）。你说黑或红都行，这版先给红；想看墨日我再出一版。
