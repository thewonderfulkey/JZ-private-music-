## JZ 音乐助手 v2.1.58：「跳过」与「高山流水」齐平

按 23:15 那条新录屏（249 帧 / 30fps / 8.3s）量的：

| 量什么 | 读数 | 换算 |
|---|---|---|
| 胶囊高度 | 48px（左弧弦高 43px 反推） | 34dp ✓ 确认是 v2.1.57 这一版 |
| 胶囊竖向中心 | y≈71px | — |

也就是说：胶囊中心原来在 86dp，标题墨色中心在 126dp —— 差了整整 40dp，正好高出一行标题。

**改法**：胶囊中心落到 126dp（= 标题墨色中心）。44dp 热区居中 → 热区上沿 `y = 104.dp`（原 64dp）。
落位后胶囊 109..143dp，标题墨色 110.5..141.5dp —— 两者上下沿几乎重合，视觉上就是同一条水平线。
横向不动（距右缘 18dp），点按逻辑、跳过动效都没变。
