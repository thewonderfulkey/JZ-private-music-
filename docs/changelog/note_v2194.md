## 1. 「其他版本」全被标成原唱

**根因**：`loadRecVersions` 里判原唱只做了「歌手对得上」这一条，歌名后缀和专辑性质完全没看。
于是 `我们都一样 (Live)`、`我们都一样 (DJ混音版)`、`我们都一样 (2016张杰Just For Star演唱会)`
这些统统被盖上原唱印——你录屏里那一屏就是证据。

**改法**：新增唯一口径 `RecognizeAdapter.Judge.isStudioOriginal()`，**五条同时满足**才印：

| 条件 | 说明 |
|---|---|
| 歌手对得上 | 识别歌手；命中综艺/现场版时用 `canonicalSingers` 推出来的歌手 |
| 歌名是裸名 | `StudioPick.isCleanTitle`：没有 `(Live)`／`(DJ混音版)`／`(演唱会)` 这类后缀 |
| 歌名无版本词 | 再兜一层 `VARIANT_TITLE`（伴奏/翻唱/remix/混音/串烧…） |
| 专辑是正式专辑 | 不是现场/综艺节目，且**专辑名不等于歌名**（同名合集不算） |
| 时长正常 | 60 秒以上（排除片段） |

界面印子和自动起播择优共用这一份判定，不会再出现"两处口径打架"。

## 2. 《我很想爱他》唱的是林俊杰，却识别成 Twins

**根因（大概率）就是第 3 条**：识曲时 App 自己的播放恢复了，麦克风录到的是**它自己放的 Twins 版**
（截图里悬浮栏正是 `我很想爱他 / Twins · QQ` 在播放），指纹当然认成 Twins。
所以这条不是识别算法错，是"录音源被污染"。

**这版做的**：
- 修掉第 3 条（见下），从根上断掉"自己放给自己听"；
- 结果卡新增一行提示：同批候选里有别的歌手时，写「如果不是 XXX 唱的，看下面「同批候选」」，
  一眼能看到换人；
- 如果修完第 3 条、用真实外放还会认错，那就是指纹本身把两个录音认混了（同一伴奏/翻唱），
  只能靠换通道或让用户挑版本——这一点我不粉饰。

## 3. 识曲中途自己又响起来

**根因**：暂停只挡住了"继续播"，挡不住**别的路径重新起播**。识曲那 12 秒里，至少三条路会走到 `PlayerManager.play()`：
缓存落盘后切本地源、自动连播的 `advanceAfterTrackEnd`、取流失败后的跨平台兜底重试。

**改法**：在 `PlayerManager` 里加播放闸门。识曲一开始就 `holdPlayback("recognize")`，
`play()` 入口直接拦（日志 `JZ_PLAY: play blocked by recognize`），识别结束/取消/报错一律 `releaseHold()`。
逐个调用点去堵会漏，堵入口才干净。

## 4. 酷我永远是 0 条 —— 真凶是解析器

不是接口挂了，也不是变体过滤。**`splitTopLevel` 把记录的 `{` `}` 直接吞掉了**：

```
原实现：  '[' '{' -> depth++        // 只加层级，没把 { 写回片段
结果：    切出来是  'NAME':'x','ARTIST':'y'
下游：    parseSingleQuotedDict 要求 startsWith("{") → 全部 null → 0 条
```

**改法**：括号照抄进片段，同时补上**引号感知**（值里出现 `{`/`}`/`,` 不再把层级算错——歌词里很常见）。
另外两处加固：`rn` 20→50；变体不再直接丢弃（有原曲只给原曲，全是变体时退回变体，绝不再 0 条）。

**设备实测**：`KUWO=41`。

## 5. 网易云/部分 QQ 没有封面

- **网易**：`/api/search/get` 只给 `picId`（拼出来的 URL 全是 404）。现在搜完补一次
  `/api/song/detail?ids=[...]`（20 首一次），那里有 `album.picUrl`，网易自己就能出真封面。
  设备实测：`我很想爱他` 三首全部拿到 `p1/p2.music.126.net` 真图。
- **QQ**：仍走 `albummid` 拼 `y.gtimg.cn`（本来就能用）。
- **酷我**：`MVPIC → img1.kuwo.cn/wmvpic`（约八成有）。
- **酷狗**：`trans_param.union_cover`。

仍可能缺图的只剩"四个平台都没给图"的条目，此时落本地水墨占位（不会出现空白框）。

## 6. 说好 4 平台，实际只有 3 个、还没有酷狗

**根因**：酷狗**从来没注册进 `SearchService`**（v2.1.9 因为"搜索能连、取流没有后端"被整体废弃，注释还在代码里）。
另外它的搜索宿主 `mobilecdn.kugou.com` 证书与域名不匹配，就算注册了也会抛异常。

**改法**（两条一起补，否则会出现"能搜不能放"）：
- 搜索：宿主换成 `mobiles.kugou.com`（证书正常），重新注册 → 现在是真 4 平台；
- 取流：新增 `KugouPlayInfoAdapter`，走官方 `m.getSongInfo.php?cmd=playInfo&hash=`，匿名 200 给 `sharefs.kugou.com` 直链；
  拿不到直链的（付费/版权曲）由既有的"同曲跨平台补源"接手，不会变成死条目。

**设备实测**：`platforms=4 QQ=50 NETEASE=50 KUWO=41 KUGOU=30`。

## 缺口

1. **第 2 条只做到"断掉污染源 + 给换人入口"**：如果真机外放仍把 Twins 和林俊杰版认混，那是指纹本身的极限，需要换通道（例如再接一家）才能解决。
2. 酷狗取流只覆盖免费曲（实测 8 首里 3 首有直链），其余靠跨平台补源；若四个平台都没有，仍会落到"无源"。
3. 网易封面补请求是"搜索后追加一次"，弱网下最多多等约 300ms；失败就跳过，不影响搜索。
4. 模拟器仍无真实麦克风，识曲是用注入的 12 秒 PCM 验的。
