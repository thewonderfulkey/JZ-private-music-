JZ Music · Windows 桌面版  v2.1.95
==================================================

一、怎么打开
  双击本文件夹里的「JZ Music.exe」。
  装了桌面快捷方式的话，桌面上的「JZ Music」也可以。

二、文件夹说明（都在这个文件夹里，整个拷走就能搬机）
  JZ Music.exe        主程序
  app\  runtime\      程序本体和自带的 Java 运行环境（别删、别单独移动）
  Download\           下载的音乐自动保存在这里
  Log\                运行日志（desktop.log / play.log / crash.log）
  Cache\              播放缓存与预取缓存，可以随时清空，不影响听歌
  Data\               设置、收藏、播放历史、下载记录（删掉 = 恢复出厂设置）
  Backup\             一键备份（设置 → 数据与备份 → 立即备份）
  说明\               本说明、更新日志、卸载说明、常见问题
  卸载 JZ Music.exe   卸载程序

三、常用操作
  ×           收进系统托盘，音乐继续播放；左键单击托盘图标唤回窗口
  −           普通最小化到任务栏
  Esc         返回上一层
  搜索框回车  四平台同时搜索（QQ / 网易云 / 酷我 / 酷狗）
  托盘右键    显示主界面 / 退出 JZ Music

四、下载的音乐去哪了
  默认就在本文件夹的 Download\ 里。想换地方：设置 → 下载位置 → 更改目录。
  「恢复默认」会回到 Download\。

五、卸载
  运行「卸载 JZ Music.exe」，或：设置 → 应用 → JZ Music → 卸载。
  卸载时可选保留 Download（音乐）和 Data（配置）。

六、出问题了怎么办
  把 Log\ 整个文件夹打包发出来即可；有 crash.log 的话一定带上。
  想恢复干净状态：关掉程序，删掉 Cache\ 和 Data\，再打开就回到初始状态（收藏和设置会清空）。
